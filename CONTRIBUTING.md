# Contribuir a Reservia

1. Crea una rama descriptiva.
2. Antes de implementar, añade o actualiza la especificación en `specs/`.
3. Escribe tests para reglas de dominio y casos de uso.
4. Mantén los módulos aislados.
5. Documenta decisiones relevantes como ADR.
6. Usa commits pequeños y descriptivos.

Los nombres, reglas y errores deben pertenecer al dominio de reservas; evita abstracciones genéricas sin una necesidad concreta.
